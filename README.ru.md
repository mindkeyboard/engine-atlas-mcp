# Engine Atlas MCP

Engine Atlas MCP — инструмент заполнения [Engine Atlas](https://octane-loader.utmsoft.ru/ru/reference/),
справочника по устройству движка Asphalt 8. Он даёт вашему ИИ режим редактирования сайта:
всё, что может сделать человек на карточке, модель делает инструментами, а ход исследования
сохраняется вместе с правками.

[English version](README.md)

## Главная идея

Справочник заполняет сообщество. Человек может править карточки на сайте руками, но
исследовать движок вручную долго. Поэтому правки пишет ваш ИИ, а вы смотрите на результат.

MCP ничего не хранит и ничего не публикует. Это рабочий инструмент поверх сайта:

- модель читает то, что сайт уже показывает;
- изучает код игры в вашей Ghidra;
- заполняет карточки в режиме редактирования и записывает, как пришла к выводам;
- вы проверяете её работу на сайте и отправляете на рассмотрение.

Заметки и основания уходят вместе с правкой. Ценность работы с ИИ именно в этом: видно, как
получен каждый вывод.

## Как это работает

```text
  ваш ИИ  ──MCP──>  engine-atlas-mcp  ──HTTPS──>  octane-loader.utmsoft.ru
                     │          │                 каталог, карточки, языки
                     │          └────────────────  Ghidra на вашем компьютере
                     │                             код игры
                     │  файл правок
                     └───────────  браузер с режимом редактирования и «Моими правками»
```

Правки общие: вы видите правки ИИ на карточках, ИИ видит ваши, перезагружать страницу не нужно.
Локально лежит только файл ещё не отправленных правок. Базы и копий справочника нет.

| Что может модель | |
|---|---|
| Читать | классы, методы, свойства, примеры, заметки и основания на русском и английском |
| Искать | по именам классов и функций, в изученных классах и по тексту на выбранном языке |
| Изучать | декомпиляция, вызывающие и вызываемые функции через Ghidra |
| Править | статьи, назначения и описания методов, свойства, примеры, основания, переводы, читаемое имя класса |
| Вести исследование | заметки, вопросы и гипотезы, которые уходят вместе с правкой |
| Управлять правками | список как в «Моих правках», подпись, комментарии, языки, проверка, удаление |
| Выгружать и отправлять | файл OED для модов, экспорт и импорт правок, отправка на рассмотрение |

## Что понадобится

- **Python 3.11** или новее.
- **Клиент с MCP:** Claude Code, Codex, Antigravity или другой.
- **Ghidra обязательна.** Карточки пишутся по реальному коду, поэтому нужны
  [Ghidra](https://github.com/NationalSecurityAgency/ghidra) и плагин
  [Ghidra MCP](https://github.com/bethington/ghidra-mcp).
- **Браузер:** Chrome, Edge или Firefox. Safari не даёт сайту связаться с компьютером.

## Установка

```sh
pip install git+https://github.com/mindkeyboard/engine-atlas-mcp
```

1. Скачайте [`libasphalt8.so`](https://octane-loader.utmsoft.ru/downloads/libasphalt8.so)
   и откройте его в Ghidra. Импорт оставьте с настройками по умолчанию и дождитесь конца
   анализа. Затем включите плагин Ghidra MCP.
2. Подключите сервер к своему клиенту:
   **[инструкция для Claude Code, Codex и Antigravity](docs/clients.ru.md)**.
3. Проверьте готовность:

   ```sh
   engine-atlas-mcp doctor
   ```

   Все строки должны быть `[ok]`.

## Как пользоваться

Дальше всё делается обычными просьбами. Правила работы модель получает от сервера сама.

1. **Попросите изучить класс.**

   > Изучи класс gin::AspectRatioContainer в Engine Atlas.

2. **Откройте правки на сайте.** Модель даст ссылку вида
   `https://octane-loader.utmsoft.ru/ru/reference/?view=edits&mcp=1`. Браузер один раз
   спросит разрешение на доступ к устройствам в локальной сети: разрешите. Правьте сами что
   угодно, модель это увидит.
3. **Проверьте работу второй сессией.** Лучше другой моделью:

   > Ты критик. Проверь мои правки gin::AspectRatioContainer по роли критика из руководства.

4. **Отправьте результат.** Нажмите «Отправить» в «Моих правках» или скажите модели:

   > Подпиши правки своим именем и отправь их на рассмотрение.

Какие модели брать и как отличить хороший результат от плохого, рассказано
[в документации Engine Atlas](https://octane-loader.utmsoft.ru/ru/guide/octane-devtools/engine-atlas/mcp).

## Вопросы

**Где лежат правки?** В браузере и в файле `~/.engine-atlas/edits.json`, пока вы их не
отправите. Сервер связывает файл со страницей через адрес `127.0.0.1:47615`, который отвечает
только самому сайту.

**Можно без браузера?** Да. Модель сама работает с правками и отправляет их, а сайт нужен,
чтобы смотреть глазами.

**Что такое OED?** Файл, который передаёт знания о классе сборке мода. Что в нём и как им
пользоваться, рассказано [на сайте](https://octane-loader.utmsoft.ru/ru/guide/octane-devtools/engine-atlas/oed).

**Другой адрес сайта?** `--site` или `ENGINE_ATLAS_SITE`, адрес Ghidra — `--ghidra` или
`GHIDRA_MCP_URL`. Обычно это нужно только разработчикам сайта.
